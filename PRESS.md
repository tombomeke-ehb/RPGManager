# RPG Manager — Press Kit

One-liner
- RPG Manager is a lightweight, terminal RPG about hero building and text-driven adventures.

Short description
- A clean, extensible console RPG demo built with .NET 8. Create a hero, pick a class, equip items, and choose between exploration and combat in a text-driven loop. Designed to grow into a small, story-lite adventure while staying approachable for learning and iteration.

Key features
- Hero classes: Warrior and Mage (more to come)
- Equipment: melee weapons, bows, quivers with inventory limits
- Saves: JSON save files with optional custom save directory
- Cross-platform: Windows, macOS, Linux (console)
- WIP roadmap: encounters, combat depth, progression, locations
